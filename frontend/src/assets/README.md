# 🎨 Kenvue Assets

This folder is reserved for future brand assets including:

- **Logos**: Kenvue brand logos in various formats (SVG, PNG)
- **Icons**: Healthcare and product category icons
- **Images**: Product photos, hero images, backgrounds
- **Graphics**: Illustrations, infographics, charts

## Usage

When adding assets to this folder:

1. **Organize by type**: Create subfolders (logos/, icons/, images/)
2. **Use descriptive names**: `kenvue-logo-primary.svg`, `healthcare-icon-pill.png`
3. **Include multiple formats**: SVG for scalability, PNG for compatibility
4. **Optimize file sizes**: Compress images for web use

## Integration

Reference assets in your templates:

```html
<img src="../assets/logos/kenvue-logo-primary.svg" alt="Kenvue Logo">
<img src="../assets/icons/healthcare-icon.png" alt="Healthcare">
```
